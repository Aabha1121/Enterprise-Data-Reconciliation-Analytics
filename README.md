\# Enterprise Data Reconciliation \& Transaction Analytics



\## Project Overview

This project focuses on reconciling enterprise transaction data and performing data analytics to identify important business insights.



\## Tools Used

\- Python

\- Pandas

\- NumPy

\- SQLite

\- Matplotlib

\- Jupyter Notebook

\- Git \& GitHub

\- Power BI



\## Current Status

The transaction data has been reconciled and validated successfully.



Key results:

\- Total Transactions: 94,902

\- Total Revenue (USD): 261,241,851.63

\- Average Transaction (USD): 2,752.75



\## Project Objective

To validate transaction data, perform exploratory data analysis, create visualizations, and develop a Power BI dashboard for business insights.
## Data Validation

The reconciled transaction dataset was checked for missing values, duplicate records, invalid amounts, and missing exchange rates.



All major reconciliation checks were completed successfully.
